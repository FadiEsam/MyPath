# Project Overview

## 1. Project Name

MyPath

## 2. Project Summary

MyPath is a personal platform for managing professional development, learning activities, projects, work time, and freelance progress.

The system helps the user organize learning, practice new skills, track project work, and understand how time and effort are spent.

The first version is designed for personal use on a local computer. The system may later grow into a broader platform with separate views for clients, recruiters, and public portfolio visitors.

## 3. Problem Statement

Learning and freelance work often involve several separate tools, files, and websites.

For example:

- Courses are tracked in one place.
- Skills and learning progress are recorded somewhere else.
- Projects and their phases are managed separately.
- Work hours are recorded manually or not recorded at all.
- Client payments and project costs are tracked in separate records.

This separation makes it difficult to understand the relationship between learning, practical experience, time, and financial results.

The project aims to bring these related records into one organized system.

## 4. Main Goals

The system aims to:

1. Organize personal learning activities and courses.
2. Track skills, knowledge, and practical experience.
3. Manage projects and their work phases.
4. Record work sessions and time spent on activities.
5. Connect learning and practical work with relevant skills.
6. Support freelance service and financial tracking as the system develops.
7. Provide useful summaries and reports based on recorded data.
8. Create a foundation for future portfolio and professional-facing views.

## 5. Primary User

The primary user is the developer who owns and manages the platform.

The first version focuses on one person's activities and records. It does not require a public registration system or multiple user accounts to provide its initial value.

Future versions may support other users and different access permissions.

## 6. Main Concept

The platform connects three important areas:

### Learning

Courses, learning resources, study time, and learning outcomes.

### Practical Development

Skills, projects, project phases, tasks, and recorded work sessions.

### Professional Progress

Services, portfolio projects, freelance activities, financial records, and reports.

These areas should work together where useful, without forcing every record to be connected to every other record.

## 7. Current Technology

The initial implementation uses:

- **Backend:** PHP without a framework.
- **Frontend:** HTML, CSS, and JavaScript.
- **Database:** PostgreSQL running locally on the developer's computer.

Laravel, React, and other technologies may be introduced later when they provide a clear benefit.

Learning a new framework is not a requirement for continuing development.

## 8. Long-Term Direction

The platform may eventually provide different views for different purposes:

- **Personal workspace:** Managing learning and projects.
- **Public portfolio:** Presenting selected skills and projects.
- **Client view:** Presenting services and managing client work.
- **Recruiter view:** Presenting relevant skills, projects, and experience.

These views may use the same underlying system and shared data where appropriate, while controlling which information each audience can access.

## 9. Project Success

The project is successful when it reliably helps its owner organize learning and practical work, record meaningful information, and make better decisions based on that information.

Success is measured by usefulness, data quality, maintainability, and the ability to evolve the system without unnecessary rebuilding.
